# Changelog

All notable changes to SwiftEspeak will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure with Swift Package Manager
- C bridging module (CEspeak) for eSpeak-NG integration
- Basic SwiftEspeak library implementation
- SwiftEspeakCLI command-line tool
- Test suite structure
- GitHub Actions workflows for CI/CD
- Development workflow documentation
- Branch protection setup

## [0.1.0] - TBD

### Added
- First experimental release
- Basic text-to-speech synthesis functionality
- Voice discovery and selection
- Audio file generation
- Multi-language support
- Swift-native API with error handling
- Command-line tool for terminal usage
- Support for macOS 11.0+ and iOS 14.0+

### Notes
- This is an experimental release and not production-ready
- API is subject to change without notice
- Features may be incomplete or non-functional
